# 🎲 운세 주사위 게임 🔮

별자리와 사주를 결합한 독특한 주사위 게임!

## ✨ 게임 특징

### 🌟 별자리 시스템 (성향)
- **12개의 별자리**마다 고유한 능력치와 특수 스킬 보유
- 생년월일을 기반으로 별자리 자동 계산
- 각 별자리는 **게임 플레이 스타일**을 결정
  - 힘, 행운, 지혜, 매력 등의 기본 스탯 부여
  - 별자리별 특수 능력으로 주사위에 영향

### 🔮 사주 시스템 (운)
- **태어난 년/월/일/시**를 기반으로 사주팔자 계산
- 천간지지와 오행(목화토금수)으로 **일일 운세** 판단
- 운세에 따라 게임 보정치 적용
  - 대길: +30% 보너스
  - 길: +15% 보너스
  - 평: 보정 없음
  - 흉: -20% 패널티

### 🎮 게임 밸런스
나쁜 운세에도 재미있게 플레이할 수 있도록 설계:

1. **별자리 특성으로 운 보완**
   - 물고기자리: 운이 나쁠 때 자동 보정
   - 게자리: 낮은 주사위 결과 리롤 가능
   - 쌍둥이자리: 2번 굴려서 높은 값 선택

2. **연속 성공 보너스**
   - 연속으로 좋은 결과가 나오면 추가 보상
   - 황소자리는 이 효과가 더욱 강력

3. **누적 보너스 시스템**
   - 염소자리는 플레이할수록 보너스 증가
   - 장기 플레이에 유리

4. **운세 변동**
   - 오행 상생/상극 관계로 매일 운세 변화
   - 나쁜 운이 계속되지 않도록 설계

## 🎯 게임 방법

1. **생년월일시 입력**
   - 태어난 날짜와 시간대를 선택
   - 자동으로 별자리와 사주 계산

2. **운명 확인**
   - 나의 별자리 성향과 능력치 확인
   - 사주팔자와 오늘의 운세 확인

3. **주사위 굴리기**
   - 주사위를 굴려서 점수 획득
   - 별자리 특성과 운세 보정이 자동 적용
   - 최고 점수 달성을 목표로!

## 📂 파일 구조

```
├── index.html      # 메인 게임 페이지
├── style.css       # 스타일시트
├── zodiac.js       # 별자리 시스템
├── saju.js         # 사주 계산 시스템
└── game.js         # 게임 메인 로직
```

## 🚀 실행 방법

웹 브라우저에서 `index.html` 파일을 열면 바로 플레이 가능!

## 💡 게임 디자인 철학

> "나쁜 운세도 재미있게!"

이 게임은 운세 기반 게임의 밸런스 문제를 해결하기 위해 만들어졌습니다:

- ❌ 나쁜 운세 = 플레이 불가능
- ✅ 나쁜 운세 = 어려운 도전 + 별자리 특성으로 극복

**핵심 원칙:**
1. 운세는 게임의 난이도를 조절
2. 별자리는 플레이 스타일을 결정
3. 나쁜 운세에도 역전 가능한 특수 능력 제공
4. 장기 플레이 시 누적 보너스로 보상
